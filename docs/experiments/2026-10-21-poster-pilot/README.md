# 포스터 분류 파일럿 실험 기록 (2026-10-20 ~ 21)

Teachable Machine(TM) 단독 분류(1차)와 OCR 기반 2차 후처리를 같은 test 35장으로 비교한 실험 기록이다. 설계와 규칙은 `docs/teachable-machine-integration.md` 12장을 따른다.

## 결과 요약

| 방식 | 정확도 | macro-F1 | 자동 제안 비율 | 자동 제안 중 정답 | 처음 보는 기관 정확도 |
|---|---|---|---|---|---|
| A. TM만 (1차) | 31% (11/35) | 0.214 | 34% | 50% (6/12) | 24% (n=21) |
| B. TM + 키워드 | 71% (25/35) | 0.652 | 29% | 90% (9/10) | 62% (n=21) |
| C. TM + 임베딩 | 34% (12/35) | 0.237 | 9% | 33% (1/3) | 29% (n=21) |
| D. TM + 키워드 + 임베딩 + 합의 규칙 (서비스 적용) | 71% (25/35) | 0.652 | 26% | 89% (8/9) | 62% (n=21) |

- 신호별 단독 1위 정확도(참고): TM 31%, 키워드 74%, 임베딩 49%.
- A에서 틀리고 D에서 맞힌 경우 14건, 반대 0건(McNemar 정확 검정 p ≈ 0.0001).
- 정확도 95% 신뢰구간(Wilson): A 약 19~48%, D 약 55~84%.
- 키워드가 하나도 걸리지 않은 포스터 6장(17%)은 TM 결과로 판정됐다.

## 실험 조건

- 데이터: 포스터 180장, 7개 분야(pilot-7-v1). train 144장, test 35장, OOD 1장(평가 제외). 라벨 목록 `manifest.csv`, 라벨 규칙 `labeling-review.md`.
- TM 모델: 2026-10-20T14:55:07.142Z, 전처리 pad-square-v1. 기본 설정으로 1회 학습.
- 후처리 버전: keywords-v1, embed-v1(Xenova/multilingual-e5-small, 참조 벡터 151개), postprocess-v1(TM 0.3 / 키워드 0.35 / 임베딩 0.35, 2개 이상 신호 일치 + 최종 점수 0.50 이상일 때만 자동 제안).
- 공정성: 키워드 사전(`keywords-v1.json`, `keyword-review.md`)과 분야 설명문(`field-descriptions-v1.json`)은 train 사진의 OCR 결과와 라벨 규칙만 보고 만들었고, 결합 비율과 판정 규칙과 함께 평가 전에 고정했다. test는 1차와 2차에 각 1회 사용했고, 결과를 본 뒤 규칙을 바꾸지 않았다.

## 한계

- test가 35장으로 작고, LAW_POLICY와 CAMPUS_NOTICE는 2장씩이다.
- 같은 test 세트를 1차와 2차에 모두 사용했다(2차 규칙은 test를 보지 않고 고정).
- 임베딩의 기여가 작았다(C 34%). 분야 간 점수가 고르게 퍼져 결합에서 영향이 약했다.
- 키워드 단독(74%)이 D(71%)보다 1장 더 맞혔다. TM 점수가 한쪽에 강하게 몰릴 때 글자 신호를 이기는 경우가 있다. 비율은 사전 고정값이라 이번 실험에서는 바꾸지 않았다.
- 큰 제목만 있고 장식 글꼴인 포스터는 OCR이 글자를 거의 읽지 못한다.

## 파일

| 파일 | 내용 |
|---|---|
| `tm-only-eval-1st.json`, `.md` | 1차 평가(TM만) |
| `tm-only-eval-rerun.json`, `.md` | 같은 모델로 다시 실행한 TM 평가. 1차와 수치가 같아 재현성 확인 |
| `postprocess-comparison.json`, `.md` | 2차 단계별 비교(A~D) |
| `postprocess-comparison.csv` | 이미지별 신호와 결과. OCR 원문은 넣지 않음 |
| `manifest.csv`, `labeling-review.md` | 라벨 목록과 라벨링 규칙 |
| `keywords-v1.json`, `keyword-review.md`, `field-descriptions-v1.json` | 키워드 사전과 분야 설명문(v1 확정본) |

포스터 이미지와 OCR 원문 CSV는 저작권과 안전 원칙에 따라 저장소에 넣지 않는다.
